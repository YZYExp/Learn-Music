# 术语与阅读路线

| 术语       | 本书中的含义                                 | 再读      |
|------------|----------------------------------------------|-----------|
| 激励       | 给发声系统输入能量，如拨、击、吹、拉         | 02、04    |
| 共鸣       | 系统对特定频率响应较强；不是凭空创造能量     | 02        |
| 基频       | 周期声音的基础重复频率；感知音高还与听觉有关 | 02        |
| 泛音       | 基音以上的分音，不保证整数倍关系             | 02        |
| 谐波       | 频率为基频整数倍的成分                       | 02、04    |
| 包络       | 参数随时间变化的轮廓，常指振幅变化           | 02、19    |
| 体鸣       | 器体本身参与主要发声                         | 14        |
| 膜鸣       | 绷紧的膜为主要振动元件                       | 13        |
| 弦鸣       | 绷紧的弦为主要振动元件；击弦也属于此类       | 04—08、15 |
| 气鸣       | 以空气振动为关键的乐器大类                   | 09—12、16 |
| 自由簧     | 舌片能穿过框口平面运动的簧结构               | 12        |
| 音域／音区 | 可使用的音高范围／范围内相对高低的区域       | 05—17     |
| 织体       | 多条音乐线索如何叠置、交替与配合             | 17        |
| 节拍／拍号 | 音乐时间的组织／一种记谱标记                 | 18        |
| 拍频       | 接近频率叠加出现的强弱起伏，不是节拍         | 18—19     |
| 律制       | 音高之间比例关系的组织方式                   | 18        |
| 音分       | 表示音程比例的单位；平均律半音为100音分      | 18        |
| 拾音器     | 把某种振动转成电信号；不同类型原理不同       | 06、16    |
| 合成／采样 | 用信号模型生成声音／以录音为声音材料         | 16        |
| MIDI／音频 | 演奏控制信息／实际声音的信号或记录           | 16、22    |

这些是入门释义，不替代完整声学和乐器学定义。

## 三条可选路线

- 喜欢听音乐：01 → 19 → 任意家族章 → 17 → 18。
- 想学一种乐器：01 → 对应家族章 → 20 → 21 → 22。
- 喜欢原理与制作：02 → 03 → 04 → 09—16 → 22。

第一次不必记下全部器种。能说清两个相近乐器的一个结构差别，再听到相应演奏差别，就已经形成了可以继续扩展的知识。
